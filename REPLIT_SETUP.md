# Replit Deployment Guide

Quick guide to run the LinkedIn Post Generator on Replit!

## Setup Steps

### 1. Import from GitHub (You've Done This!)
✅ You've already imported the repository into Replit

### 2. Add Your API Key
1. Click the **Secrets** (🔒) icon in the left sidebar
2. Click **"New Secret"**
3. Enter:
   - **Key:** `ANTHROPIC_API_KEY`
   - **Value:** Your Anthropic API key (get it from https://console.anthropic.com/)
4. Click **"Add Secret"**

### 3. Run the App
1. Click the big green **"Run"** button at the top
2. Wait for it to install dependencies (first time takes 1-2 minutes)
3. Watch for the message: "Application ready!"
4. Replit will show you a preview window with your app

### 4. Access Your Public URL
- Replit automatically gives you a public URL
- Look for the URL at the top of the preview pane
- Share this URL with anyone - they can use your LinkedIn Post Generator!

## Troubleshooting

**"ANTHROPIC_API_KEY environment variable not set"**
- Make sure you added your API key in the Secrets tab
- Click "Stop" and "Run" again to restart the app

**Dependencies taking too long to install**
- This is normal on first run (1-2 minutes)
- Subsequent runs will be much faster

**Can't see the preview**
- Click the "Open in new tab" icon to view in your browser
- Or copy the URL from the address bar

## Getting Your Anthropic API Key

1. Go to https://console.anthropic.com/
2. Sign up or log in
3. Click "API Keys" in sidebar
4. Click "Create Key"
5. Copy the key (starts with `sk-ant-`)
6. Paste into Replit Secrets

**Note:** You may need to add a payment method, but cost is very low (pennies per post).

## Using the App

Once running, you can:
- Select from 8 post types (Story, How-To, List, etc.)
- Provide context about what you want to write
- Choose tone (professional, casual, inspirational)
- Choose length (short, medium, long)
- Generate viral-optimized LinkedIn posts!
